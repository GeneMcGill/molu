# 外部方法论库

> 本引擎的方法分两类，必须区分：
> - **本引擎数据结论**：从 899 篇语料实测得出（标注 `【实测】`）
> - **外部方法论**：引自 4A / 咨询 / 媒体业的成熟框架（标注 `【外部】`）
>
> **为什么要区分**：外部框架是行业惯例，不是实证结论。混用会让用户以为有数据支撑。

## 怎么用这个库

### 正确用法

```
"这个洞察用的是 JTBD 视角【外部】，但结论来自你自己的读者【实测】"
```

### 错误用法

```
"根据 Account Planning 理论，你的读者应该是 25-35 岁女性"   ← 把框架当数据
```

**纪律**：
1. 引用外部框架时**必须标注出处**
2. **不能用外部框架替代实测结论**
3. 外部框架提供**提问角度**，不提供**答案**
