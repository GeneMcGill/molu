# 短视频脚本工具

> **video**（短视频）· 口播脚本、分镜、字幕切分

**短视频是跨平台适配成本最高的一类。**

---

## 为什么单独做一个

源语料实测暴露了根本矛盾：

```
对话段落占比   中位 1.1%   ← 几乎没有对话
故事型文章      4.8%        ← 只有 43 篇
观点论述型     67.3%        ← 主力是议论
```

**议论压缩出来就是念稿感极强的视频。**【实测】

所以这个模块的第一条规则是：**不要从原文压缩，要从故事模板重新组装**——用结构不用文字。

---

## 第一步：定时长、平台、形式

1. **时长** → 决定字数
2. **平台** → 决定语域与节奏
3. **形式** → 口播 / 情景 / 图文配音 / 无人出镜

没给就默认：60 秒 + 视频号 + 口播。

### 时长换算

```
句长中位 21 字 ≈ 5.2 秒/句（按中文口播 4 字/秒）
60 秒   ≈ 240 字
90 秒   ≈ 360 字
180 秒  ≈ 720 字
```



---

## 第二步：前 3 秒——决定完播率

**必须命中一个缺口感。** 四选一：

| 类型 | 做法 | 例 |
|---|---|---|
| **反问** | 直接问，让观众想反驳 | 「如果一个男人对你温柔体贴，符合所有好男友标准，那他就是真的爱你吗？」 |
| **反常断言** | 说一句违反常识的话 | 「努力是普通人最大的骗局。」 |
| **具体场景** | 一秒代入 | 「我认识一个商务男士，沉默寡言，无趣透顶，活像一段呆木头。」 |
| **结论前置** | 先给结果再解释 | 「我这辈子做过最错的决定，是当初听了所有人的劝。」 |

**禁止的开头**：
- 「大家好，我是 XX」（浪费 3 秒）
- 「今天想跟大家聊聊」（没有缺口）
- 铺垫背景（观众已经划走）

---

## 第三步：主体——用反转结构

### 60 秒标准骨架

```
0–3s    钩子（反问/反常断言/具体场景/结论前置）
3–10s   具体情境（谁、在哪、发生了什么）
10–40s  反转（结果与预期相反）
40–55s  结论（一句金句）
55–60s  互动引导
```

### 关键：反转是短视频的发动机

语料里有 **605 条反转/对比故事模板**（其中 ≤100 字的 313 条），每一条都是**结构**。

用法是替换人物场景，保留节奏：

```
原结构：他问我可以交换电话吗 → 我本来想拒绝 → 因为赢了钱不好意思就给了
        → 后来又见了两次 → 他表白我答应了 → 原因：他的头发是自然卷

新用法：HR 问我期望薪资 → 我本来想报低点 → 因为不好意思就报了
        → 后来又面了两轮 → 给我 offer 了 → 原因：我简历上的一个错别字
```

### 排比节奏（口播必备）

**三连排比**——三个同结构短句，一次比一次重。这是口播最有效的节奏器。

```
你不说，就没人知道。
你不闹，就没人当回事。
你把所有委屈都咽下去，
世界只会觉得你消化能力不错。
```

**每 60 秒至少一个三连。**

---

## 第四步：字幕切分

**一屏一句，6–15 字。**

源语料 **≤15 字的段落有 12,341 段（占 14.9%）**，可作字幕参考。【实测】

切分规则：
- 按句号/问号/感叹号切，不按逗号切（除非逗号前后都很长）
- 单屏不超过 15 字（手机竖屏 2 行内）
- 关键词单独一屏（制造停顿感）

---

## 第五步：结尾——互动引导

短视频的结尾不是总结，是**给一个动作**：

| 动作类型 | 说法 |
|---|---|
| 提问式 | 「你身边有没有这样的人？」 |
| 立场式 | 「同意的扣 1，不同意的评论区见」 |
| 悬念式 | 「下一条讲怎么办」 |
| 直给式 | 「收藏起来，下次用得上」 |

**不要**说「今天就分享到这里，感谢观看」。

---

## 第六步：语域适配

| 平台 | 语域 | 注意 |
|---|---|---|
| 抖音 / 视频号 | 口语化，可用痞子腔 | 「特么」「老子」可用，但密度比长文低 |
| TikTok / Shorts / Reels | 英文口播 | **痞子腔全部删除**，不直译 |
| YouTube 长视频 | 可用长文骨架 | 需章节化 |

**英文适配的三类损失**：
- 痞子腔无对应语域 → 删
- 文化专有词（凤凰男/直男癌）→ 解释性替换
- 集体主义归因 → 改个体视角

## 素材获取

```bash
KB_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]:-$0}")/../.." 2>/dev/null && pwd)"
[ -d "$KB_ROOT/inlets" ] || KB_ROOT="$(cd "$(dirname "$0")/../.." && pwd)"

python3 "$KB_ROOT/kb.py" search CAS <关键词> 5   # 短视频故事模板
python3 "$KB_ROOT/kb.py" get GLD 10             # 结尾金句
```

## 自检（9 项）

- [ ] 前 3 秒命中缺口感（反问/反常/场景/结论前置）？
- [ ] 字数符合时长（60 秒 ≈ 240 字）？
- [ ] 有一个明确的反转？
- [ ] 至少一个三连排比？
- [ ] 字幕每屏 ≤15 字？
- [ ] 结尾给了明确动作？
- [ ] 全文朗读一遍，**没有书面语**？
- [ ] 没有编造具体案例当论据？
- [ ] 没有点名真人真公司？

---

## 边界

不用于：新闻报道 / 调查 / 真实悲剧的情绪化加工 / 时政历史题材。

三条硬红线：不编造具体案例当论据、不点名真人真公司、不消费真实悲剧。
