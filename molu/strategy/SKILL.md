# 内容策略

> **strategy**（策略）· 定位、人群、节奏、形式

**洞察回答「为什么」，策略回答「做什么、给谁、多久一次」。**

对应职能：4A 的 **Brand Strategy** / **Media Planning**、媒体的 **Editorial Policy**。

---

## 一、四个决策

### 决策 1：位置（Positioning）

**一句话说清：你在这个领域里占哪个位置。**

| 模型 | 做法 | 适合 |
|---|---|---|
| **对立位** | 站在主流说法的反面 | 有明确靶子时 |
| **升维位** | 把常识问题提到更高维度 | 有理论储备时 |
| **代言位** | 替一群人说出他们说不出的 | 有共情能力时 |

**自检**：这个位置能否用一句话说明，且这句话会让一部分人**不舒服**？
（不能让任何人反感的定位 = 没有定位）

### 决策 2：人群（Audience）

**不要做「泛受众」。** 三层结构：

```
核心层（30%）  会转发的人 —— 决定传播
影响层（50%）  会看但不会转 —— 决定数据
外延层（20%）  偶然触达 —— 决定破圈
```

**实测参考**：语料 899 篇标题里，含「我」378 条、含「你」284 条【实测】——
**第二人称和第一人称是拉近距离的主要手段**。

### 决策 3：节奏（Cadence）

| 频率 | 适合 | 风险 |
|---|---|---|
| 日更 | 追热点型 | 质量不稳 |
| 周 2-3 | 观点型 | 需要选题储备 |
| 周 1 | 深度型 | 涨粉慢 |

**周内内容类型分配**（参考媒体编辑室惯例）：

```
周一  共鸣型    周初情绪最低，共鸣最强
周三  观点型    周中讨论度高
周五  深度型    周末有阅读时间
```

⚠️ **说明**：这是基于内容类型的**逻辑分配**，不是平台算法规律——后者无法验证。

### 决策 4：形式（Format）

按平台分工，不重复生产：

| 内容类型 | 主平台 | 复用去向 |
|---|---|---|
| 深度长文 | 公众号 / 知乎 / Substack | → 拆成小红书卡片 |
| 观点短文 | X / 微博 | → 扩成长文 |
| 故事节拍 | 短视频 | → 沉淀成长文案例 |
| 金句 | 小红书封面 / 朋友圈 | → 长文结尾 |

**一次生产，多处复用。** 见 `reuse`。

## 二、策略矩阵（把四个决策填进一张表）

```markdown
# 内容策略：{账号/项目名}

## 位置
{一句话定位}

## 人群
- 核心层：{谁}
- 影响层：{谁}
- 外延层：{谁}

## 节奏
- 频率：{周 N 次}
- 分配：{周一 X / 周三 Y / 周五 Z}

## 形式
| 内容类型 | 主平台 | 复用去向 |
|---|---|---|

## 不做什么
{明确排除的内容类型}
```

**「不做什么」这一栏最重要。** 没有它，策略等于没写。

## 三、多平台分工（不重复劳动）

```
        ┌──────────────┐
        │  核心观点/洞察  │   ← 只生产一次
        └───────┬──────┘
                │
    ┌───────────┼───────────┐
    ↓           ↓           ↓
  长文         短文        视频
（公众号）   （X/微博）   （短视频）
    ↓                       ↓
 拆卡片                    截图
（小红书）                （朋友圈）
```

**关键原则**：**同一个观点，不是同一篇文字。**

---

## 四、策略自检（6 项）

- [ ] 定位能用一句话说清，且会让一部分人不舒服？
- [ ] 人群分了层，且核心层是**会转发的人**而不是**会看的人**？
- [ ] 节奏是可持续的（不是「日更」这种做不到的承诺）？
- [ ] 每个平台有**不同形式**，不是同一篇复制粘贴？
- [ ] 写了「不做什么」？
- [ ] 策略能指导具体决策（拿到一个选题能判断该不该做）？
