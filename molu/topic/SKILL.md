# 选题生成器

> **topic**（选题）· 输入领域，产出 20 个带依据的选题

**输入**：一个领域 / 行业 / 产品或人群
**输出**：20 个可直接写的选题，每条带标题 + 切入角度 + 依据

---

## 核心方法：选题不是"想"出来的，是"换"出来的

不要凭空头脑风暴。用**四个来源**做机械替换：

| 来源 | 产出类型 |
|---|---|
| **靶子库** | **观点型** —— 找被默认接受的错误共识，反驳它 |
| **情绪缺口库** | **共鸣型** —— 找读者喊疼的地方 |
| **观点断言库** | **深度型** —— 可展开成论证的判断句 |
| **标题模板库** | 套标题结构 |

---

## 第一步：确认三件事

问用户（已给的不要重复问）：

1. **领域**是什么（越具体越好）
2. **读者**是谁
3. **要哪种选题** —— 观点型 / 共鸣型 / 深度型 / 混合

默认：混合，各占三分之一。

---

## 第二步：查靶子与痛点

用引擎的数据层查询，**不要直接读大文件**。

`kb.py` 在引擎根目录（本模块上两级）。调用前先定位：

```bash
KB_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]:-$0}")/../.." 2>/dev/null && pwd)"
[ -d "$KB_ROOT/inlets" ] || KB_ROOT="$(cd "$(dirname "$0")/../.." && pwd)"

python3 "$KB_ROOT/kb.py" search TGT <关键词> 10    # 找靶子（观点型选题源）
python3 "$KB_ROOT/kb.py" search EMO <关键词> 10    # 找情绪缺口（共鸣型选题源）
python3 "$KB_ROOT/kb.py" search VOI <关键词> 10    # 找观点断言（深度型选题源）
python3 "$KB_ROOT/kb.py" get GLD 10                # 取高复用金句
```

**换语料不需要改这一步** —— `kb.py` 永远读当前进气阀。

也可直接读本地素材库（离线可用）：
`references/靶子库.md` · `references/情绪缺口库.md` · `references/观点断言库.md` · `references/标题模板库.md`

---

## 第三步：从靶子生成观点型选题

**每条靶子的用法**：

```
靶子：年龄和阅历成正比
→ 选题：《35 岁没长进，不是因为你笨，是因为你一直在做不需要动脑的工作》
```

**关键**：不要照抄靶子原文，要**换成用户领域的说法**。

### 常见靶子类型（可直接套）

| 靶子类型 | 结构 | 例 |
|---|---|---|
| **道德正确型** | "X 是对的，但实际没人这么做" | 「努力就会有回报」 |
| **经验教条型** | "老话说 X，但 X 已经不成立" | 「稳定工作最安全」 |
| **自我安慰型** | "用 X 解释失败" | 「我只是没遇到机会」 |
| **集体默认型** | "大家都这么做，但没人问为什么" | 「先攒钱再谈理想」 |

---

## 第四步：从情绪缺口生成共鸣型选题

**痛点即选题**：读者在哪里喊疼，就从哪里切。

```
情绪缺口：明明很努力了，还是觉得自己不够好
→ 选题：《你不是不够努力，你是被"必须更好"绑架了》
```

---

## 第五步：套标题模板

读 `references/标题模板库.md`（25 个从真实标题反推的结构）。

**最常用的 8 个**：

```
X，X              ← 两段式（占 48.3%）
你不是X，你只X     ← 免责式
X，就是X           ← 定义式
X：X，X            ← 标签+结论
如何X？            ← 方法式
我X，我只X         ← 立场式
X，我X了           ← 叙事式
X的NX              ← 清单式
```

**每个选题至少给 2 个标题变体**（一个套模板，一个不套）。

---

## 第六步：输出格式

```markdown
## 领域：{领域}
## 读者：{读者}

### 观点型（7 个）

**1. 《标题A》**
- 备选：《标题B》
- 靶子：{要反驳的共识}
- 切入：{从哪个角度打}
- 依据：{为什么这个靶子成立}

**2. ...**

### 共鸣型（7 个）
（同上结构，把"靶子"换成"痛点"）

### 深度型（6 个）
（同上结构，把"靶子"换成"待展开的断言"）
```

---

## 第七步：自检（6 项）

- [ ] 20 个选题里，至少有 5 个**不是**"如何做 X"式的方法论题？
- [ ] 每个选题都能说出**读者为什么会点**？
- [ ] 没有选题需要编造具体案例才能成立？
- [ ] 没有选题涉及时政 / 真实悲剧 / 具体真人？
- [ ] 至少 8 个选题的标题是「两段式」？
- [ ] 每条都标了依据，不是凭感觉？

---

## 选题质量的三个判断标准

| 标准 | 通过 | 不通过 |
|---|---|---|
| **有痛感** | 读者能投射自己的经历 | 纯知识科普 |
| **有立场** | 观点明确，会有人反对 | 中立客观，谁都不得罪 |
| **能成立** | 不靠编案例也能论证 | 必须编个故事才讲得通 |

**实测依据**：语料 899 篇里 **67.3% 是观点论述型**，只有 4.8% 是纯故事型【实测】。
**所以选题应该以"观点"为主，不要以"故事"为主。**

---

## 如果用户要"每周发什么"

给他一个**排期表**：

```
周一（共鸣型）  → 情绪缺口，周初共鸣最强
周三（观点型）  → 反驳靶子，周中讨论度高
周五（深度型）  → 判断句展开，周末有阅读时间
```

并说明：这个排期是基于"内容类型"的逻辑分配，**不是平台算法规律**——后者无法验证。

## 边界

不生成：时政 / 真实悲剧 / 涉及具体真人的选题。

不承诺：流量预测（无法验证）、平台算法规律（无法验证）。
