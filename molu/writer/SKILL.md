# 内容写作引擎

> **writer**（写稿）· 长文/图文，按平台规格产出可发布稿

把题目变成可发布的稿子。**不扮演任何人**，只提供方法与素材。

所有方法都来自 899 篇语料的实测统计，每条规则后面标注依据。

---

## 第一步：确认三件事

开工前必须问清（用户已给的不要重复问）：

1. **目标平台** —— 决定字数、标题长度、段落上限
2. **目标读者** —— 越具体越好
3. **想要的姿态** —— 愤怒 / 焦虑 / 疗愈 / 自嘲 / 清醒

用户没说就默认：公众号 + 通用读者 + 共鸣姿态。**不要为了问而问，一次问完。**

---

## 第二步：分配心理位置（最容易被跳过，但最重要）

写第一个字之前，先决定**读者点开那一刻被安排成谁**。八选一或选二：

| 位置 | 读者会做什么 | 适合平台 |
|---|---|---|
| 被辜负的人 | 转发给当事人 | 小红书 / 朋友圈 |
| 终于清醒的人 | 收藏 + 关注 | 公众号 / 知乎 |
| 忍无可忍的人 | 评论 + 争吵 | X / 微博 / 短视频 |
| 被世界亏欠的人 | 共鸣 + 转发 | 小红书 / 朋友圈 |
| 比别人更早看透的人 | 转发证明自己有见识 | 知乎 / X |
| 正在错过机会的人 | 收藏 | 公众号 |
| 有资格审判别人的人 | 评论 | 短视频 / X |
| 被作者独家理解的人 | 关注 | 公众号 / 小红书 |

> 普通内容回答问题。有效果的内容**重新分配尊严**。

选完位置，后面每一句话都为它服务。**位置不明确就动手，稿子会散。**

---

## 第三步：选题——找伤口，不找观点

```
真实痛苦 + 简单归因 + 清晰（但模糊化）的敌人 + 可转发姿态
```

**判断标准**：
- ✅ 能让读者投射自己的经历
- ❌ 能被数据或定义说清楚的事实题
- ❌ 需要专业知识才能判断的题

---

## 第四步：标题

### 实测基准

```
899 篇标题长度：中位 16 字（p25=13, p75=18, p90=20）
含 ！或 ？：38.6%
拆字感叹型（老！子！就！是！）：仅 1.3%，12 条
```

**所以：标题中位 16 字，不必都带感叹号。** 拆字感叹是稀有手法，不要当常规武器用。【实测】

### 三件套

**1. 重新命名痛苦**

```
累 → 低能量          社交失败 → 能量不匹配
没钱 → 结构性困境     被拒绝 → 价值感被打压
```

**2. 给一个免责出口**

```
不是你不行，是你太懂事
不是你失败，是规则变了
不是你敏感，是对方没有边界
```

**3. 让标题本身能当朋友圈配文**

### 模板（可用，但每次至少出一个不带模板的）

```
别再把 X 包装成 Y 了。
真正毁掉你的，不是 X，而是 Y。
一个人开始废掉，是从 X 开始的。
你不是 X，你是一直在向 Y 证明 Z。
为什么越 X 的人，越 Y？
成年人最大的清醒，是 X。
```

### 输出要求

**至少 3 个变体**，标注情绪基调：

- 愤怒版 → 转发率最高
- 焦虑版 → 收藏率最高
- 疗愈版 → 关注率最高

## 第五步：正文（按平台规格）

### 平台规格（硬约束）

| 平台 | 字数 | 标题上限 | 段落上限 | 备注 |
|---|---|---|---|---|
| 公众号 | 1800–3000 | ≤24 | 30 | 源格式，改动最小 |
| 知乎 | 2000–4000 | ≤30 | 40 | 需补论据，去"雾状归因" |
| Substack | 1200–2000 | ≤60 字符 | 25 | 英文语境换语域 |
| 小红书 | 300–800 | **≤20** | 15 | 拆 3–5 张卡片 |
| Instagram | 150–300 | ≤30 字符 | 12 | 转视觉隐喻 |
| X 单条 | ≤140 | — | — | 直接取单元 |
| 抖音 / 视频号 | 220–260 字/分钟 | ≤15 | 15 | **叙述改对话** |
| 播客 | 按分钟 | — | 30 | 补听觉过渡 |

### 结构（三段式）

**开头（前 3 秒/前 2 行）**

实测真实开头分布：短断言 **37.0%** / 题记式 29.8% / 设问 13.2% / 故事起手 2.1%【实测】

⚠️ **题记式从 2015 年的 92.7% 降到 2018 年的 4.3%，现代写法不建议用。**【实测】

推荐用短断言或设问开头：

```
设问式：如果一个男人对你温柔体贴，符合所有好男友标准，那他就是真的爱你吗？
断言式：所谓颜值，就是你所有生活习惯的相加。
```

**中段：把一个人扩大成一代人**

```
一个朋友的离职   → 一代人的困境
一段失败关系     → 亲密关系的本质
一家公司的内耗   → 职场潜规则
```

靠**节奏**，不靠证据。每 300–400 字插一个金句把情绪夯实（源单篇中位 3–4 个金句）。

**结尾：金句封口，独立成段**

任务不是总结，是**给读者一个转发理由**。

```
你不是 X，你只是终于不想再 Y。
真正的成长，不是 X，而是终于敢 Y。
```

### 段落纪律

```
段落中位 21 字；≤30 字占 71.1%
```

**一句一段。** 这不是风格选择，是格式要求——≤15 字的段落有 24,841 个，天然适合竖屏字幕和手机阅读。【实测】

## 第六步：让四类读者同时进场

| 读者 | 给他什么 | 他会 |
|---|---|---|
| 委屈的人 | 外部敌人 + 结构性解释 | 转发 |
| 焦虑的人 | "很多人已经开始了" | 收藏 |
| 审判的人 | 冲突案例 | 评论 |
| 想被赦免的人 | 替他翻译失败 | 关注 |

**自检：这四类人在稿子里都能找到自己的位置吗？**

实测支持：共鸣 739 / 自嘲 815 / 幽默 592 / 愤怒 447 / 温暖 391，不同情绪走不同单元类型。【实测】

---

## 第七步：埋互动入口

正文里至少埋 2 个：

1. 一个明显可反驳的极端句
2. 一个让人想讲自己经历的情绪缺口（"你身边有没有这样的人？"）
3. 一个能让两派人互相看不顺眼的价值判断
4. 一个低成本的"你怎么看"

## 素材获取

```bash
KB_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]:-$0}")/../.." 2>/dev/null && pwd)"
[ -d "$KB_ROOT/inlets" ] || KB_ROOT="$(cd "$(dirname "$0")/../.." && pwd)"

python3 "$KB_ROOT/kb.py" get GLD 15            # 高复用金句（标题/封面/结尾）
python3 "$KB_ROOT/kb.py" search CAS <关键词> 5  # 可模仿故事结构
python3 "$KB_ROOT/kb.py" find <关键词>          # 跨类型检索
python3 "$KB_ROOT/kb.py" stats                  # 当前语料的分布特征
```

也可读本地素材：`references/金句库_高复用.md` · `references/可模仿故事模板.md`

**引用纪律**：可以引用素材文件里的原句。文件里没有的，**不要凭记忆编造"原作者说过"**。

---

## 第八步：出稿前自检（11 项）

- [ ] 心理位置明确，且全篇为它服务？
- [ ] 标题 ≤ 平台上限，出了 3 个情绪变体？
- [ ] 字数、段落长度符合平台规格？
- [ ] 开头是短断言或设问，**没有用题记式**？
- [ ] 中段有"一个人 → 一代人"的扩大？
- [ ] 每 300–400 字有一个金句？
- [ ] 结尾金句独立成段，能单独截图？
- [ ] 四类读者都能找到位置？
- [ ] 埋了 ≥2 个互动入口？
- [ ] 全文没有编造具体案例当论据？
- [ ] 没有点名具体公司/真人？

十一项里至少过九项才出稿。

## 跨平台适配红线

| 损失 | 处理 |
|---|---|
| **痞子腔**（特么/老子）在英文语境 | **直接删除**，不直译 |
| **文化专有词**（凤凰男/直男癌） | 需解释性替换 |
| **集体主义归因** | 英文更强调个体，需调归因方向 |

**可迁移的只有结构**：短段落 / 反转 / 金句收口 / 四类读者。

---

## 边界

不用于：新闻报道 / 调查 / 非虚构 / 学术 / 科普 / 时政 / 真实悲剧的情绪化加工。

**三条硬红线**：

1. **不编造具体案例当论据**
2. **不点名真人真公司**
3. **不消费真实悲剧**

写完必须过 `guard` 审核才能发布。
