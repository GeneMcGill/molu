# 主题复用器

> **reuse**（复用）· 把一个主题榨出 10 个不同角度

**输入**：一个主题 + 已写过的角度
**输出**：10 个不重复的切入角度

---

## 一个反直觉的实测结论

我原本打算做「系列化」Skill，先查了 899 篇语料：

```
上下篇 / 之一之二 / 续集     0 条
第 N 期 / 系列              0 条
正文里"上次写过""接着上次"    0 条
```

**899 篇里没有任何"系列"痕迹。**【实测】

所以她**不做系列，做主题复用**——同一主题反复写，每次换角度。

真实的复用密度：

```
「朋友圈」  12 次
「月薪」    10 次
「情商」     4 次
「实习生」   3 次
```

## 五种换角度方式（全部有真实例）

### 1. 换人称

从「我」→「她」→「那个 XX 的人」。

```
原角度：我的助理月薪才5万
换人称：月薪5万的女人，私生活都是什么样的
换人称：那个拼命要进娱乐圈的女生，现在月薪1800
```

实测：第一人称开头 129 条（14.3%），第三人称开头 30 条（3.3%）

### 2. 换设问

从断言 → 设问。

```
原角度：所谓情商高，就是懂得好好说话      （断言）
换设问：那些情商高的人，为什么都不快乐？    （设问）
```

实测：为什么/凭什么 42 条（4.7%）

### 3. 换对象（最高产）

同一现象换一个人群。

```
月薪4000到4万        → 应届生
月薪8000在北京        → 一线白领
月薪1800的娱乐圈女生  → 追梦者
月薪5万的女人         → 高收入女性
月薪3万+的产后妈妈    → 母亲
```

**一个主题至少能换 5–8 个人群。**

### 4. 换时间（升级定义，不是重复）

实测的「情商」演变：

```
2015  所谓情商高，就是懂得好好说话
2016  所谓情商高，就是要有分寸感
2017  幽默，是最高级的情商
2018  那些情商高的人，为什么都不快乐？
```

**注意**：换时间不是重复，是**升级定义**。每一年的「情商」定义都不同。

### 5. 换对立面

从正面写一次，反面写一次。

```
正面：我为什么辞掉稳定的工作
反面：稳定工作到底给了什么（同一主题，反向立场）
```

## 组合出 10 个角度

**每个角度 = 一种换法 × 一个人群 × 一个立场**

用矩阵法，先列人群，再列换法：

```
             换人称   换设问   换对象   换时间   换对立面
应届生         ✓        ✓        ✓       ✓
一线白领       ✓        ✓        ✓       ✓
高收入者       ✓        ✓        ✓       ✓
中年转行者     ✓        ✓        ✓       ✓
全职妈妈       ✓        ✓        ✓       ✓
```

横竖各取一个，就能得到 10+ 个不重复的角度。

## 一条纪律：复用 ≠ 重复

**判断标准：把两篇的标题并排放在一起，读者会不会觉得"这不是写过吗"。**

合格：

```
我的助理月薪才5万
月薪5万的女人，私生活都是什么样的
```

不合格：

```
我的助理月薪才5万
我的助理月薪五万块
```

**换的是角度，不是措辞。**

## 进阶：多立场矩阵（谨慎使用）

同一事件可以拆成对立立场，各写一篇。

| 事件 | 立场 A | 立场 B |
|---|---|---|
| 加班 | 公司凭什么牺牲普通人的生活？ | 为什么年轻人越来越不扛事？ |
| 亲密关系 | 别再为低质量关系消耗自己 | 普通男人正在被情绪价值绑架 |
| 家庭 | 你以为是关心，其实是在控制 | 有些父母的爱本质是勒索 |

⚠️ **两条限制**：

1. **绝不能在同一个号里左右横跳** —— 那是人设崩塌
2. **对立立场容易滑向煽动对立**（性别 / 地域 / 阶层 / 代际），写之前先过 `guard` 的边界检查

这条是**矩阵号的商业策略**，不是单账号的内容策略。

## 自检（7 项）

- [ ] 10 个角度里，有没有两个其实是同一个角度换了词？
- [ ] 每个角度都换了**人群或立场**，而不只是换标题说法？
- [ ] 没有靠编造具体案例才能成立的角度？
- [ ] 没有涉及时政 / 真实悲剧 / 具体真人的角度？
- [ ] 每个角度都写清了「与已写角度的差异」？
- [ ] 至少 5 个角度的标题是「两段式」？
- [ ] 这些角度**分开发**能各自独立成立，不依赖前文？

## 边界

不生成：时政 / 真实悲剧 / 具体真人相关的复用角度。

不承诺：流量预测、平台算法规律（无法验证）。

**不做账号运营建议** —— 那是另一件事，本模块只做选题复用。
